# 씬 제작 가이드

씬은 `Scene = (nx, ny, t, ar) => [r, g, b]` 형태의 순수 함수다. 렌더러가 매 프레임
화면을 셀 그리드로 나누고 **셀 중심마다 한 번씩** 호출한다 — 1080p 기준 약 1만 회/프레임.

## 좌표계와 인자

- `nx, ny`: 화면 정규 좌표 (0..1). 좌상단이 (0, 0).
- `t`: 초 단위 시간. 흔들림·반짝임 같은 느린 애니메이션에 사용.
- `ar`: 가로/세로 비율. **거리 계산 시 반드시 dx에 곱할 것** — `Math.hypot((nx-cx)*ar, ny-cy)`.
  곱하지 않으면 원이 화면 비율대로 찌그러진다.
- 반환: `[r, g, b]` (0..255, 클램핑은 렌더러가 한다).

## 작성 패턴

레이어를 위에서 아래로 덮어쓰는 식으로 그린다. 뒤(하늘·벽)부터 시작해
앞(전경 오브젝트)이 변수 `r, g, b`를 덮어쓴다.

- **그라데이션 배경**: `let r = 14 + ny * 6; ...` — ny/nx에 비례하는 밑색.
- **부드러운 마스크**: `smooth(edge0, edge1, x)` — edge0→edge1로 0→1 보간.
  인자를 뒤집으면(`smooth(0.115, 0.02, d)`) 안쪽이 1인 원형 마스크가 된다.
- **혼합**: `r = lerp(r, targetR, mask)` — 마스크 강도만큼 목표색으로.
- **붓결·질감**: `Math.sin(nx * A + ny * B + t * C)` 조합. 주파수(A, B)를 높이면 결이 촘촘해진다.
- **점묘 질감**: `hash((nx * N) | 0, (ny * N) | 0)` — N 격자로 양자화한 결정적 노이즈
  (해바라기 씨앗, 자갈, 마을 창문).
- **소용돌이**: `Math.sin(atan2(dy,dx) * arms - dist * scale + t) * Math.exp(-dist * falloff)`
  — 별이 빛나는 밤에·자화상 배경의 공식.
- **불꽃 실루엣(사이프러스)**: 중심선 x를 `sin(ny * k + t)`로 흔들고, 폭 안쪽이면
  `smooth`로 어두운 색을 혼합.
- **타원 로컬 좌표(얼굴 등)**: `hx = (nx - cx) * ar / rx; hy = (ny - cy) / ry;`
  `hx*hx + hy*hy < 1`이면 내부. 내부 디테일은 hx/hy 기준으로 그리면 위치·크기 조정이 쉽다.

## 성능 규칙

- 셀 수만큼 호출되므로 **씬당 예산은 대략 수십 회의 산술 연산 + 짧은 고정 루프**.
- 오브젝트 목록(별, 꽃, 액자…)은 모듈 상수 배열로 두고 for 루프로 돈다. 개수는 ~12개 이하 유지.
- 함수 내부에서 배열·객체를 생성하지 말 것 (GC 압박). 반환 배열만 예외.
- `Math.pow` 대신 곱셈, 가능하면 `smooth` 재사용.

## 타일 해상도 감각

셀 크기(`Work.cell`, CSS px)가 곧 "붓의 굵기"다. 15면 1080p에서 가로 ~128타일.
얼굴처럼 디테일이 필요한 씬은 12–13, 풍경은 14–15가 적당하다.
디테일의 최소 크기는 셀 두세 개 폭(약 0.02~0.03 nx)보다 작아지면 뭉개진다 —
그보다 작은 요소(눈, 창문)는 오히려 타일 1~2개로 찍히는 게 모자이크답게 보인다.
